obs-dv-capture - installation (Windows)
=======================================

Prerequisites
-------------
1. OBS Studio 30 or newer, 64-bit (Windows 10 / 11).
2. The camcorder connected over IEEE-1394 (FireWire), powered on, in CAMERA
   mode (or VCR mode for tape playback).
3. The 1394 host controller must use the LEGACY OHCI driver:
     Device Manager -> IEEE 1394 Bus host controllers
     -> right-click the Texas Instruments controller -> Update driver
     -> Browse my computer -> Let me pick
     -> untick "Show compatible hardware"
     -> Manufacturer: Microsoft
     -> "1394 OHCI Compliant Host Controller (Legacy)"
     -> finish, then REBOOT.
4. Close PotPlayer / AMCap / WinDV before opening the source in OBS:
   a 1394 DV device can only be opened by one program at a time.

Installation - RECOMMENDED (ProgramData)
----------------------------------------
The zip contains a single folder named "obs-dv-capture". Copy that whole
folder into:

    C:\ProgramData\obs-studio\plugins\

Tip: paste this path into the Explorer address bar:

    %PROGRAMDATA%\obs-studio\plugins

Create the "plugins" folder if it does not exist. Copying may prompt for
administrator permission - click Continue.

So the result is:

    C:\ProgramData\obs-studio\plugins\obs-dv-capture\bin\64bit\obs-dv-capture.dll
    C:\ProgramData\obs-studio\plugins\obs-dv-capture\data\locale\en-US.ini

IMPORTANT: on Windows, OBS does NOT scan the %APPDATA%\Roaming\obs-studio\
plugins folder (that path is used on Linux/macOS). Use ProgramData.

Legacy layout (only if you cannot use ProgramData)
---------------------------------------------------
Copy the files into the OBS installation directory as two separate pieces:

    C:\Program Files\obs-studio\obs-plugins\64bit\obs-dv-capture.dll
    C:\Program Files\obs-studio\data\obs-plugins\obs-dv-capture\locale\en-US.ini

After installing
----------------
Fully quit OBS (also check the system tray icon), then start OBS again.

Usage
-----
In OBS: Sources -> Add -> "DV/1394 FireWire Capture".
Select the camcorder in the "Device" list (usually "Microsoft DV Camera and
VCR"), keep "Capture embedded DV audio" enabled, then OK.
If the device list changes, use "Refresh device list".

Expected signal: PAL 720x576 25fps YUY2 (or NTSC 720x480 29.97fps),
embedded 16-bit PCM audio.

The device is released automatically when the source is not visible in any
active scene (so other capture software can use it).

If the source stays black, check Help -> Log Files -> View Current Log for
lines starting with "[obs-dv-capture]".
